# Third-party data

## Game titles (`src-tauri/assets/game-titles.tsv`)

The serial-to-title table bundled with the app is generated from
[libretro-database](https://github.com/libretro/libretro-database) by
`scripts/build-game-titles.mjs`.

That data is licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), so the generated
file keeps the same license and attribution. The rest of Slot2Sync is licensed
under the [GPL-3.0](./LICENSE).
